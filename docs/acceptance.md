# 0.1.0 开发验收清单

本清单为首版开发依据，当前已实现。正式插件通过的自动化与原生验收证据见 [验收记录](verification.md)。勾选表示已有直接检查证据；未勾选项保留为进一步验证场景，不表示功能未实现。早期原型另见 [原型检查记录](prototype-verification.md)。

## 主流程

- [x] 从空库新建决定，三个必填内容、今天与默认 +30 天正确保存；重载后仍存在。
- [x] 未填必填内容时显示具体错误，键盘和点击采用同一校验，无丢字或重复记录。
- [x] 补记历史决定，修改或清空回访日期；早于决定日期时阻止保存。
- [x] 今天及逾期项进入待回访；未来、未安排和已结束项不进入。
- [x] 详情能同时读到首次记录与最新回访；没有回访时有清楚的下一步入口。
- [x] 保存「部分达到 + 继续观察」回访，追加历史并更新日期；队列更新而当前详情保持。
- [x] 保存「暂时无法判断 + 暂不安排」，决定仍为观察中，不继续提示。
- [ ] 保存「未达到 + 结束回访」，历史保留，全部列表可查；重新开启可选择新日期或留空。
- [x] 单独调整日期只新增安排历史；不会生成假回访或覆盖上次结果。
- [x] 同一决定进行第二次回访，历史倒序可读，最新结果对照正确。
- [x] 补记过去回访的发生日期时，最新保存的后续安排仍正确生效。

## 原记录与经验

- [x] 更正原记录保留首次快照及更正原因，可切换对照版本；过去回访仍指向当时使用版本。
- [x] 补充想法追加时间与文本，不静默替换原来的理由或预期。
- [x] 更正一次回访，原文及修订均可查看；当前安排保持，已导出经验不被静默改写。
- [x] 经验内容可编辑后保存为独立 Markdown，含来源决定及回访链接。
- [x] 再次保存同一回访经验时打开已有文件；用户主动另存才生成副本。
- [x] 经验已保存但源索引写入失败时，重试不重复新建，重载能修复关联。
- [x] 移到回收站后决定不再列出；关联资料与独立经验仍在。

## 文件、日期与恢复

- [x] 写入失败保留输入和待保存内容，显示具体文件与原因，修复后可重试。
- [x] 打开表单后外部修改源文件，旧表单保存被拒绝；原文件不被覆盖。
- [x] 缺失标记、无效 YAML、重复 ID、无效日期、悬空版本引用及未来版本均有明确错误。
- [x] 程序重载后从 Markdown 完整重建决定、回访、安排和经验关联。
- [x] 重命名或移动关联笔记后，历史与当前引用同步，已打开表单不保留过期路径。
- [x] 删除关联文件显示失效状态；打开其他有效文件不受影响。
- [x] 月末、闰年、跨年与夏令时的日历加法正确；本地午夜和恢复聚焦时更新到期项。
- [x] URL 校验与文本渲染不会执行用户内容，不后台访问网址。
- [x] 演示载入与真实记录分开；清除演示不移除用户文件，不产生重复演示项。

## 界面和可用性

- [ ] 中英双语覆盖命令、设置、表单、错误、状态及生成正文；不翻译用户文字或改路径。
- [ ] 深浅主题及自定义强调色跟随宿主；状态有文字，键盘焦点可见。
- [ ] 1,280px、900px、760px、460px、360px 插件容器均能操作，无水平溢出。
- [x] 窄面板能搜索切换所有决定，返回详情，保存回访与经验。
- [ ] 弹窗焦点限制、Escape、未保存放弃确认与关闭后焦点返回均正确。
- [x] Cmd/Ctrl + Enter 在保存中不会重复创建；保存失败后可继续修改并重试。
- [ ] 零记录、无到期、搜索无结果、无经验和异常文件都有明确操作入口。
- [x] 搜索覆盖理由、预期和回访；状态过滤不改变全局待回访计数。
- [x] 导航切换、重读数据与语言变更保留合理的选择和阅读位置。
