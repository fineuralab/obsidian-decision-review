# 决策复盘助手：0.1.0 首版设计

日期：2026-11-03。状态：0.1.0 已按此设计实现。真实 Obsidian 验收与发布范围见 [验收记录](verification.md)，早期可点击原型继续保留供对照。

## 产品要完成的事

适合会在 Obsidian 里做学习、创作和个人项目的人。在作出一个值得回头看的决定时，花一分钟写下理由和预期；结果出现后，带着当时的记录回来，看看哪些判断成立、下次会怎样改。

首版的成功标准是一位新用户能独立完成：记录决定 → 找到到期项 → 对照预期写回访 → 决定是否继续观察 → 留下一条可复用的经验。

与已有插件的关系：投入账本围绕费用与成果，项目续接围绕进展与下一步，本插件围绕选择的理由、预期与后来结果。三个插件可以互相关联笔记，首版各自独立工作，不依赖彼此安装。

## 首版功能边界

| 优先级 | 功能 | 完成标准 |
| --- | --- | --- |
| P0 | 记录已经作出的决定 | 三个必填内容，日期有默认值；选填项渐进展开 |
| P0 | 到期回访队列 | 今天及逾期的未结束决定；日期按本地自然日判断 |
| P0 | 预期与结果对照 | 固定显示最初记录，右侧显示最近一次回访，完整历史可展开 |
| P0 | 多次回访与安排日期 | 继续观察、暂不安排、结束回访三种去向；都保留历史 |
| P0 | 全部决定与搜索 | 搜索决定、理由、预期、补充、回访及经验，支持状态过滤 |
| P0 | 库内笔记与网址关联 | 主动选择已有笔记、填写 HTTP(S) 网址，清楚显示失效引用 |
| P0 | Markdown 保存与恢复 | 一决定一文件，重载恢复、旧表单冲突保护、保存失败保留输入 |
| P0 | 更正、补充与移到回收站 | 更正生成修订；补充作为新事件；移除整个决定需要确认 |
| P0 | 使用体验 | 桌面中英双语、深浅主题、360px 窄面板、键盘操作 |
| P1，仍在 0.1.0 | 经验笔记 | 主动保存独立 Markdown，保留原决定和回访链接；保存失败可重试 |
| P1，仍在 0.1.0 | 演示与空状态 | 示例与真实记录分开，载入与清除演示需要明确入口 |

后续候选：多方案权重比较、结构化概率预测及校准、跨决策主题归纳、批量导出、移动端专项适配、AI 辅助提问。首版不设置判断总分、胜率、连胜、打卡或排行榜。个人决策的结果条件差异很大，这些数值会掩盖记录本身。

首版不调用 AI、不联网同步、不发送系统通知。到期提示在插件视图与可选状态栏内显示。截图、PDF 和其他附件可先放进库内，再作为文件引用，不单做附件导入系统。

## 新建：一分钟留下当时的想法

| 字段 | 必填 | 默认 / 交互 |
| --- | --- | --- |
| 这次做了什么决定 | 是 | 一句话，作为列表标题；例如「第三款插件先做决策复盘助手」 |
| 主要理由 | 是 | 多行文本，说明为什么选择它 |
| 期待看到什么 | 是 | 多行文本，提示「到时看到什么，你会觉得这次选择值得？」 |
| 决定日期 | 是 | 今天；允许补记历史，不能晚于今天 |
| 下次回访 | 否 | 首次建议本地今天 +30 天；补记时用户自行改期，不随决定日期静默重算 |
| 考虑过的其他选项 | 否 | 默认折叠的「补充依据」内，自由文本 |
| 最担心哪个假设不成立 | 否 | 与其他选项一起展开 |
| 相关笔记 / 网址 | 否 | 与其他选项一起展开；新建可自动预选当前笔记，由用户移除 |

三个必填文本去掉首尾空白后均不能为空。决定标题上限 160 字符，其他文本每项上限 10,000 字符。回访日期不得早于决定日期；历史决定可以安排已经到期的回访。表单显示具体字段错误，保留所有输入，聚焦第一个错误。

主按钮始终叫「保存决定」。支持 Cmd/Ctrl + Enter，与点击使用同一保存逻辑，保存中禁用重复提交。Escape 或关闭按钮在有未保存内容时询问是否放弃；取消放弃后回到原输入。首次保存失败不清空草稿。

## 回访：对照，而后追加

从到期列表点击决定，在同一工作页查看：

- 左侧「当时的判断」：决定、主要理由、预期、假设与当时关联资料。
- 右侧「最近一次回访」：实际发生了什么、预期对照、下次怎样调整。
- 尚未回访时：明确显示「还没有回访」，主按钮为「做一次回访」。

回访表单再次固定展示当时的预期，避免一边写结果一边回忆原标准。

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 回访日期 | 是 | 默认今天，位于决定日期和今天之间；可以补记，历史按发生日和创建时间排序 |
| 实际发生了什么 | 是 | 记录事实；允许阶段性结果 |
| 与当时预期相比 | 是，需主动选择 | 达到预期 / 部分达到 / 未达到 / 暂时无法判断；没有默认评价 |
| 回头看，理由或假设哪里需要调整 | 否 | 避免只凭结果评价当时判断；不强制给过程打分 |
| 下次遇到类似情况，我会 | 否 | 写具体做法，可稍后转为经验笔记 |
| 本次证据 | 否 | 关联笔记、文件与 HTTP(S) 网址 |
| 接下来 | 是 | 默认继续观察；另有暂不安排、结束回访 |
| 下次回访 | 条件必填 | 继续观察时默认今天 +30 天，必须晚于今天；其他去向清空 |

「暂时无法判断」是一种结果评价，不自动决定去向。用户仍需明确选择继续观察、暂不安排或结束。保存按钮为「保存回访」。结束回访时按钮可以标为「保存并结束回访」，旁边提示以后可重新开启。

保存后保留当前详情并显示保存结果，即使当前决定已离开到期队列，也不突然跳到另一条。详情提供「下一条待回访」；没有下一条时展示队列已处理完。列表与数量同步更新。

「调整回访日期」只改变安排，并追加安排事件，不创建空白回访。清空日期后从到期队列移出，在全部决定中显示「未安排」。重新开启已结束决定时主动选择新日期或暂不安排。

## 原记录、更正与补充

首次保存的记录始终作为对照基准。后来想法变化使用「补充想法」，追加带时间的记录。输入错字或原文缺项使用更多菜单中的「更正原记录」：保存新的修订和更正说明，原版本继续保留。

默认对照首次记录；有修订时显示「已更正 · 查看修订」，用户可切换具体版本。回访显式记住使用的记录版本，后来更正不会改写过去回访的参照物。修订展示哪几项发生变化。

首版支持更正回访，保留被更正版本并显示编辑时间；不提供单条回访永久删除。整个决定通过「移到回收站」移除，关联资料与独立经验笔记保留。

## 状态与回访队列

数据中的生命周期只有「观察中」「已结束」。界面中的到期状态根据日期派生，避免将「逾期」「待判断」误做成持久状态。

| 条件 | 界面文案 | 在到期队列 |
| --- | --- | --- |
| 观察中且日期早于今天 | 逾期 N 天 | 是 |
| 观察中且日期等于今天 | 今天回访 | 是 |
| 观察中且日期晚于今天 | MM月DD日回访 | 否 |
| 观察中且日期为空 | 未安排回访 | 否 |
| 已结束 | 已结束 | 否 |

到期队列按回访日期从早到晚，相同日期按决定创建时间排序。全部决定默认未结束在前，未结束中有日期的按日期升序，再列未安排；已结束按最后更新时间倒序。搜索和过滤只改变列表，不改变导航中的总量。

本地午夜、窗口重新聚焦、视图变为可见及每分钟检查日期变更。未结束但无日期的项不产生提醒。没有系统通知，也不要求用户每天处理。

## 工作台与信息布局

三个入口足够：**待回访、全部决定、经验笔记**。首屏不放数据仪表盘；数量只用来帮助定位待处理项。

```text
决策复盘                                    记录决定
待回访 3        全部决定 6        经验笔记 2
────────────────────────────────────────────────────
搜索 / 状态筛选       决定标题              更多
                      日期 / 回访安排
逾期 / 今天分组       [做一次回访] [调整日期]
决定列表              ┌ 当时的判断 ┬ 最近一次回访 ┐
                      │ 主要理由   │ 实际结果     │
                      │ 期待看到   │ 预期对照     │
                      │ 假设       │ 下次调整     │
                      └────────────┴──────────────┘
                      相关资料
                      回访与补充历史
```

主视图只有一套导航。左栏固定约 288px；右栏按可用宽度展开，内文最大约 88 个中文排版单位。对照区域是最有辨识度的部分：同一水平线上的两份记录，以中间细分隔线关联，安静地表现时间前后关系。

插件叶子宽度 ≥1,040px：列表 + 左右对照。760–1,039px：保留列表，对照改为上下。小于 760px：列表作为可搜索的选择面板，通过「切换决定」打开；详情占满叶子。360px 时标题换行，动作换行，对照按「当时 → 回访」排列；不出现横向滚动。判断依据为插件容器宽度，不能只看浏览器窗口。

经验页展示经验原文、来源决定、回访日期和打开笔记入口，支持关键词搜索；首版不自动生成总结。点击「保存为经验笔记」前打开编辑框，用户确认标题和内容。相同回访已保存时显示「打开经验笔记」，防止重复。源文件丢失时保留提示，提供另存一份。

## 关键页面与空状态

1. **首次进入**：显示「记下一个值得回头看的决定」，主操作「记录第一个决定」，次操作「载入演示」。
2. **没有到期项**：显示「今天没有待回访的决定」，可前往全部决定；若有未来项，注明最近日期。
3. **搜索无结果**：保留搜索和筛选，提供「清空筛选」。
4. **决定详情**：最初记录、最新回访、资料、完整历史；缺少选填内容时不显示空栏目。
5. **创建 / 回访弹窗**：聚焦第一个输入；内容较长时表单滚动，底部操作保持可见。
6. **保存失败**：表单顶部报具体文件与原因，输入保留；成功落盘后才关闭。
7. **文件异常**：工作台显示具体路径，可打开源文件修复、重新读取；不可静默覆盖异常文件。
8. **无经验笔记**：说明「回访后，可以把下次做法保存为经验笔记」，提供前往有经验内容的回访入口。

## 视觉方案与复核

使用 Obsidian 界面字体，中文由系统中文字体回退。24px 工作页标题、16px 区块标题、14px 正文、12px 日期。内容左对齐，正文行高 1.65，所有操作有清楚的文字或可访问名称。

原型参考色：主背景白 `#ffffff`、侧栏灰 `#f6f6f7`、正文 `#24252b`、次要文字 `#686973`、宿主紫 `#7054c5`、逾期琥珀 `#9a650f`。正式插件从 `--background-primary`、`--background-secondary`、`--text-normal`、`--text-muted`、`--interactive-accent` 等宿主变量取色，不固定紫色。深色使用宿主变量，状态同时配文字，不只用色彩。

设计初稿曾考虑顶部统计卡片和决策成功率；复核后移除。最需要看到的是当时的文字及现在的证据，横向对照比统计更贴近用途。两栏记录不用两张悬浮大卡片，而是共用一份有分隔的记录面板；只有选中项、主操作和对照标题使用强调色。

键盘焦点清晰可见，弹窗限制焦点并返回触发按钮；列表是可聚焦按钮，菜单支持 Escape；减少动态效果设置下不加过渡。360px 仅表示桌面窄面板适配，不构成移动端支持承诺。

## 设置与命令

设置首版保留：界面语言（跟随 / 中文 / English）、默认回访间隔（7 / 14 / 30 / 90 天）、库内数据目录、状态栏到期数量开关、载入与清除演示、重新读取。目录切换不搬迁数据，界面明确说明新路径。

命令：打开决策复盘、记录一个决定、查看待回访、为当前决定做回访、打开经验笔记。当前笔记只关联一个决定时可直接定位，多个时选择，未关联时选择已有决定。

## 开发顺序

1. 数据类型与日期规则，Markdown 读写，回访及修订事件。
2. 工作台、新建、搜索、文件选择与原生打开。
3. 对照、回访、安排、结束与重新开启。
4. 更正与补充、冲突和错误恢复、重命名处理。
5. 经验笔记、演示隔离、中英双语、深浅主题与窄面板验收。

可点击原型用于确认布局和主要动线；未模拟的文件保存错误、修订、重命名及国际化等场景以本文和验收清单为准。
