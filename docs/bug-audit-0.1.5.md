# 0.1.5 导入与历史复查记录

日期：2026-11-04。基线：0.1.4。修复版：0.1.5。结构版本继续为 `decisionReview: 1`。

本轮未复现新增的严重数据丢失或误删问题，确认并修复以下三处导入校验和展示边界问题，优先级为 P2。

| 问题 | 触发与影响 | 修复 |
| --- | --- | --- |
| 导入枚举的类型校验过宽 | `outcome: [met]` 或 `followup: [closed]` 被转为字符串后通过校验；后续严格比较时可能把应为「已结束」的回访当作观察中 | 只接受规定的字符串值。异常文件按路径报错，有缓存时保留只读快照，禁止覆盖；修复源字段后可恢复 |
| Markdown 更正历史遗漏旧版本 | 创建时间含不同时区偏移，或相同时间戳的输入数组顺序与 ID 次序不同，正文排序和界面使用的有效版本不一致，旧版本可能不展示、最新版本重复展示 | 正文使用与领域模型一致的实际时间及 ID 排序，原回访、旧更正和最新更正各展示一次 |
| 经验列表的时间顺序错误 | 导入经验的时间含不同时区偏移时，按字符串排序可能把较早笔记排在较晚笔记前 | 使用实际时间排序，相同时间用稳定 ID 决定次序 |

上述问题没有删除 YAML 源数据。插件表单生成的正常状态字段始终是字符串；本次收紧主要针对导入或手工修改的文件。原始时间字符串和用户文字不因排序而改写。

## 复现与验证

- `tests/import-regression.test.ts`：5 项新增回归在 0.1.4 上全部失败，0.1.5 全部通过。

- `tests/commit-recovery.test.ts`：另补 5 项「提交成功但确认丢失」的故障注入验证。创建和回访不会重复；经验副本可发现并关联；索引重试保留一个文件及一条关联；移到回收站不会重复操作或影响独立经验及普通资料。这些属于已有保护的补充验证。
- 全量 73 项自动化测试、严格 TypeScript 检查与构建、原有真实 Obsidian 回归、安装 ZIP 实装、源码包独立安装及构建验证均通过。详见 [验收记录](verification.md)。

## 更新

解压 `decision-review-0.1.5.zip`，替换插件目录中的 `main.js`、`manifest.json` 和 `styles.css`，重新加载插件。正常数据无需迁移。

如导入文件因列表型枚举报错，把对应字段修为单个正确字符串后重新读取。例如 `followup: [closed]` 改为 `followup: closed`。不要通过改写正文来绕过结构化数据校验。

历史正文的旧版本文字仍保存在 YAML 中，插件内历史可查看全部版本；下一次正常保存会按修正规则重建正文。只重新读取文件不会触发批量重写。
