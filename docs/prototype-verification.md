# 原型检查记录

日期：2026-11-03。对象：`prototype/` 中的独立 HTML 交互原型。

环境：本机 Chrome，通过 Playwright CLI 检查；使用 `?today=2026-11-03` 固定评审日期。通过 `node --check prototype/app.js` 语法检查。

## 通过的交互检查

- 新建日期默认今天，下次回访建议 30 天后；必填内容为空、回访早于决定日期时阻止保存。
- Ctrl + Enter 保存，数量与到期队列随之更新；刷新后能恢复浏览器中的示例，并按关键词搜索。
- 回访评价必须主动选择；保存未来日期后移出到期队列，同时保留当前详情和队列更新提示。
- 同一天多次回访展示最后一次；完整记录保留。继续观察、暂不安排、结束及重新开启均可操作。
- 经验可以保存、打开和搜索，包含来源决定；再次打开不会增加重复经验。
- 关闭未保存表单时提示，取消放弃会保留原输入，确认放弃才关闭。
- 空状态提供记录入口；重置示例后恢复为 6 个决定和 2 条经验，检查数据已清除。
- 宽浏览器内将插件面板缩到约 430px 时，列表折叠并出现切换入口，说明依据的是容器宽度。
- 360px 下可搜索、切换决定、打开回访表单，表单底部保存操作可见。
- 最后重新加载并打开、关闭回访表单时，无 JavaScript 页面错误；弹窗有可访问名称。
